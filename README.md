# 🍔 برجر هاوس — موقع مستقل لطلب الوجبات

لا يحتاج أي مكتبات ولا حسابات خارجية. فقط Node.js (الإصدار 18 أو أحدث).

## التشغيل على جهازك
```
ADMIN_PASSWORD=كلمة_سر_قوية node server.js
```
افتح http://localhost:3000 — الزبون يطلب مباشرة، والبائع يضغط 🔑 ويدخل كود البائع (الافتراضي: `hamza123`).
(على ويندوز: `set ADMIN_PASSWORD=كلمة_سر_قوية` ثم `node server.js`)

## النشر السريع على Render (الأسهل)
1. ارفع المجلد إلى مستودع GitHub.
2. في Render اختر New ← Blueprint وحدد المستودع، فيقرأ ملف `render.yaml` (خدمة مع قرص دائم لحفظ الطلبات).
3. أدخل `ADMIN_PASSWORD` عند الطلب وانتظر انتهاء النشر لتحصل على رابطك العام.
(القرص الدائم يتطلب خطة مدفوعة. الملف `Dockerfile` يصلح لأي استضافة أخرى.)

## النشر اليدوي
1. ارفع هذا المجلد على GitHub.
2. أنشئ خدمة Node.js على Render أو Railway أو Fly.io أو VPS، وأمر التشغيل: `npm start`.
3. أضف متغيرات البيئة:
   - `ADMIN_PASSWORD`: كود البائع. إن لم تحدده يكون `hamza123`؛ وإن حددته في الاستضافة فهو الذي يعمل (اكتب `hamza123` إن أردت الإبقاء عليه).
   - `DATA_FILE`: مسار ملف البيانات داخل قرص دائم (مثل `/data/data.json`)، وإلا ضاعت الطلبات والصور المرفوعة عند إعادة التشغيل (الصور تُحفظ في مجلد `uploads` بجانب هذا الملف).
4. فعّل HTTPS (توفره هذه الخدمات تلقائيًا).
5. خذ نسخة احتياطية دورية من ملف `data.json` (فيه الطلبات والقائمة والتقييمات).

## لوحة البائع
- **الوجبات**: زر «+ جديد» لإضافة أكلة (اسم، وصف، سعر، فئة جديدة اختيارية، مخزون، إضافات) مع **رفع صورة من الهاتف أو الجهاز** (تُصغَّر تلقائيًا). تعديل السعر سريع من الحقل بجانب كل أكلة، وتغيير الصورة من «تعديل».
- زر **✅ متوفر / ⛔ غير متوفر** لكل أكلة: الزبون يرى الحالة على البطاقة، ولا يمكنه طلب غير المتوفر، وله زر «المتوفر فقط» للتصفية.
- **التوصيل**: إضافة وتعديل وحذف الأماكن (الأحياء/المناطق) مع سعر التوصيل لكل مكان.

## ملاحظات
- الزبون يُعرَّف بمعرّف عشوائي في متصفحه، فإن مسح بيانات المتصفح فقد سجل طلباته (تبقى عند البائع).
- الخادم يعيد حساب الأسعار والخصم والتوصيل ولا يثق بما يرسله المتصفح، ولا يسمح للزبون بتغيير حالة طلبه.
- التحديث الفوري يتم بالاستعلام كل ٣ ثوانٍ، ويكفي لمحل صغير أو متوسط.
- لا توجد إشعارات دفع على الهاتف، التنبيه يظهر والصفحة مفتوحة عند البائع.
- الخريطة غير مضافة بعد (العنوان نصي).
